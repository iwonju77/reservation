# ADR 0009: 결제·환불 경계

## 결정

결제사는 `PaymentProvider` 뒤에 둔다. 결제 세션, 서명 웹훅, 환불은 각각 멱등 키로 보호하며 결제·환불 금액은 최소 통화 단위 정수로 저장한다. 예약 확정은 검증된 성공 웹훅만 수행한다.

결제 만료 시 예약과 좌석 점유를 해제한다. 이후 도착한 성공 웹훅은 거래에는 기록하지만 좌석을 다시 확보하지 않고 예약도 자동 확정하지 않는다. 이 경우 운영 대사와 환불 판단이 필요하다.

## 현재 범위

개발용 fake와 PostgreSQL 상태 모델까지 구현했다. 운영 결제사, sandbox 계정, 웹훅 비밀키, 환불 정책이 정해지기 전에는 production API가 결제 세션을 만들지 않는다.
