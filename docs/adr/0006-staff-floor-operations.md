# ADR 0006: 직원 현장 운영과 원자적 좌석 변경

- 상태: 승인된 개발 기준
- 날짜: 2026-11-08 (Asia/Taipei)

## 결정

직원 현장 운영은 기존 예약 엔진과 동일한 예약·점유·정책 스냅샷을 사용한다. 별도 예약 경로를 만들지 않고 직원 예약과 현장 방문도 HOLD를 확보한 뒤 같은 예약 ID를 제출한다. 직원 경로는 예약 오픈 기간을 우회할 수 있지만 영업시간, 정책, 차단과 물리적 좌석 충돌은 그대로 적용한다.

상태 변경은 reservation version을 요구한다. 승인, 거절, 도착, 착석, 퇴석, No-show와 복구는 예약 행을 잠그고 상태 이벤트와 감사 로그를 같은 트랜잭션에 기록한다. 착석은 `table_occupancies`에 현재 물리 점유를 별도로 생성하고 퇴석 때 완료한다.

테이블 재배정, 이용 연장과 예약금 없는 날짜·인원 변경은 기존 allocation을 해제하고 새 allocation을 삽입하는 하나의 트랜잭션으로 처리한다. exclusion constraint 충돌 시 전체 트랜잭션을 rollback해 원래 시간과 좌석을 유지한다. 예약금이 있는 예약 변경은 Step 10 결제 차액 절차 전까지 거부한다.

No-show 복구는 이전 실제 테이블의 점유를 다시 확보할 수 있을 때만 `CONFIRMED`로 되돌린다. 이용 연장이 다음 예약과 충돌하면 자동 덮어쓰지 않고 `requiresContact` 정보를 포함한 충돌 응답을 반환한다.

## 화면

현장 보드는 영업일별 예약 타임라인, 고객·전화·예약번호 검색, 상태 필터, 테이블 착석 상태, 30초 갱신 시각을 표시한다. 태블릿과 휴대전화에서 사용할 수 있는 큰 상태 버튼을 제공하며 제한된 당일표를 인쇄할 수 있다.

## 검증

실제 PostgreSQL에서 직원 두 명의 같은 version 동시 조작, 착석·퇴석 물리 점유, 테이블 재배정, 연장 충돌, 변경 실패 rollback, No-show 해제·복구를 검증한다.
