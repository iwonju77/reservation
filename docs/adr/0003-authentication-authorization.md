# ADR 0003: 직원 인증·매장 권한·세션 폐기

- 상태: 승인된 개발 기준
- 날짜: 2026-11-07 (Asia/Taipei)

## 결정

직원 인증은 bcrypt 비용 12의 비밀번호 해시와 PostgreSQL 세션 레코드, HS256 서명 세션 토큰을 함께 사용한다. 브라우저에는 세션 ID와 사용자 ID만 담은 토큰을 HttpOnly·SameSite=Lax 쿠키로 전달한다. 서버는 요청마다 토큰 서명뿐 아니라 세션 만료·폐기, 사용자 활성 상태, 대상 매장의 활성 멤버십과 현재 역할을 DB에서 다시 확인한다.

역할은 `STAFF < MANAGER < SYSTEM_ADMIN` 순서다. 관리자는 자기 매장에 STAFF 계정을 만들 수 있고, 시스템 관리자는 더 높은 역할의 계정을 만들고 사용자를 비활성화할 수 있다. 비활성화는 기존 세션을 모두 즉시 폐기한다. 시스템 관리자의 자기 계정 비활성화는 거부한다.

로그인 실패 5회에는 15분 잠금을 적용한다. 세션 유효기간은 8시간이다. `mfa_required` 계정은 해당 세션의 추가 인증 완료 시각이 없으면 관리자 권한 검사를 통과하지 못한다. 실제 MFA 등록·검증 수단은 운영 인증 제공 방식을 정하는 단계에서 연결하며, 그 전에는 해당 플래그를 활성화하지 않는다.

상태 변경 요청은 동일 출처를 검사한다. 로그인·로그아웃·계정 생성·비활성화 API는 일반 오류 응답에 내부 정보나 입력 비밀번호를 포함하지 않는다. 감사 로그 서비스는 password, secret, token, authorization, cookie, credential 계열 키의 값을 재귀적으로 `[REDACTED]` 처리한다.

## 이유

서명된 토큰만 신뢰하면 퇴사자 비활성화나 역할 변경이 토큰 만료까지 반영되지 않는다. DB 세션과 실시간 멤버십 검사를 결합하면 계정 탈취나 퇴사 대응 시 기존 접근을 즉시 차단할 수 있다. 매장 ID를 요청에서 받더라도 매장 멤버십을 매번 조회하므로 다른 매장의 객체 접근을 차단할 수 있다.

## 검증

실제 PostgreSQL에서 정상 로그인, 낮은 역할, 다른 매장, 비활성 사용자, 5회 실패 잠금, 로그아웃 폐기, 계정 생성, 전체 세션 폐기, 감사 로그 비밀값 마스킹을 통합 테스트한다. Next.js production build에서 모든 인증·관리자 라우트를 컴파일한다.
