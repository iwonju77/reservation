# ADR 0004: 운영 설정과 정책 게시

- 상태: 승인된 개발 기준
- 날짜: 2026-11-07 (Asia/Taipei)

## 결정

테이블, 결합 테이블, 주간 영업시간, 특별영업·임시휴무, 예약 차단, 예약 정책을 매장별 운영 데이터로 관리한다. 모든 쓰기 작업은 MANAGER 이상의 현재 매장 권한을 서버에서 확인하고 감사 로그를 남긴다.

주간 영업시간은 한 번에 전체 목록을 교체하며 같은 요일의 복수 구간과 익일 종료를 지원한다. 주 경계를 넘는 구간까지 환산해 겹침을 거부한다. 특별일은 날짜별로 하나만 존재하며 `CLOSED`에는 영업 구간을 둘 수 없고 `SPECIAL_OPEN`에는 하나 이상의 구간이 필요하다.

정책은 새 버전을 DRAFT로 만들고 적용 날짜 범위를 지정해 게시한다. 게시된 정책 본문과 규칙은 DB 트리거로 변경·직접 삭제를 거부한다. 운영 종료가 필요하면 상태만 RETIRED로 전환한다. 같은 매장의 정책 적용 범위는 PostgreSQL exclusion constraint로 겹침을 거부한다.

정책 규칙은 예약 오픈·마감, 인원 범위, 이용시간, 정리시간, 시작 간격, 승인, 최소소비, 예약금, 취소, 대기, No-show를 표현한다. 게시 전에 요일·시간·인원을 넣어 일치하는 규칙을 미리 볼 수 있다.

## 영향 확인

향후 활성 예약이 배정된 테이블을 비활성화하면 먼저 영향 건수를 반환하고 명시적 확인 없이는 변경하지 않는다. 운영 설정 응답은 활성 테이블 수와 기본·최대 좌석 합계를 함께 계산한다. 결합 테이블은 같은 매장의 활성 테이블 두 개 이상만 사용할 수 있고, 결합 최대 좌석은 구성원 최대 좌석 합계를 넘을 수 없다.

## 검증

실제 PostgreSQL에서 결합 구성 검증, 일반·자정 경과 영업시간 충돌, 특별영업, 테이블 차단, 정책 필수 규칙, 미리보기, 적용 범위 충돌, 게시 정책 불변성, STAFF 쓰기 거부를 통합 테스트한다.
