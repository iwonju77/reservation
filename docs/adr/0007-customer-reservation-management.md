# ADR 0007: 고객 예약 흐름과 관리 토큰

- 상태: 승인된 개발 기준
- 날짜: 2026-11-08 (Asia/Taipei)

## 결정

고객 예약은 날짜·인원·시간의 가용성을 확인한 뒤 HOLD를 만들고 연락처와 약관 동의를 제출한다. HOLD는 sessionStorage로 새로고침을 복구하고 서버 멱등키로 중복 클릭을 같은 요청으로 처리한다. 화면에는 서버 만료시각 기준 남은 시간을 표시한다.

고객 관리 권한은 256비트 이상의 무작위 토큰으로 부여한다. 원문 토큰은 제출 성공 응답에서 한 번만 반환하며 URL fragment로 관리 화면에 전달한다. fragment는 서버 요청 로그에 포함되지 않는다. 브라우저는 토큰을 sessionStorage에 옮기고 주소에서 즉시 제거한다. DB에는 SHA-256 해시와 만료·폐기 시각만 저장한다.

조회·취소·변경 API는 예약 ID만으로 접근할 수 없고 유효한 Bearer 관리 토큰을 요구한다. 변경과 취소는 reservation version을 검사한다. 예약금 없는 예약 변경은 새 정책·영업시간·좌석을 다시 평가하고 allocation을 원자적으로 교체한다. 예약금이 있는 변경은 Step 10 전까지 직원 문의로 거부한다.

약관·개인정보 동의는 예약별 문서 버전, 언어와 동의 시각을 저장한다. 고객 화면은 번체중문과 한국어 문구, 모바일 입력, 명확한 HOLD·승인대기·결제대기·확정 상태를 제공한다.

## 검증

잘못된 관리 토큰 접근 거부, 관리 토큰 원문 미저장, 예약 조회, 무결제 원자적 변경, 취소와 점유 해제, version 충돌을 실제 PostgreSQL에서 검증한다.
